## 2. מבוא: לוגיקה דיגיטלית וקידוד (שבוע 1)
- מערכת דיגיטלית עובדת עם אותות בדידים (0/1). אות אנלוגי → דגימה (Discretization) → קידוד (Coding).
- דוגמת המנורה: מתגים **במקביל** = OR (Lamp = A+B), מתגים **בטור** = AND (Lamp = A·B). 0 = פתוח, 1 = סגור.
- **ASCII** (1963): קוד של 7 ביטים, 128 תווים. הביט ה-8 שמור לבדיקת זוגיות (parity).
- **קודים בינאריים (תרגול 1, תרגיל בית 1):**
  - **BCD:** כל ספרה עשרונית ב-4 ביטים, למשל (843.5)₁₀ = 1000 0100 0011 . 0101. קלט 1010–1111 לא חוקי, ולכן don't care.
  - **קוד משוקלל:** משקל לכל ביט. 8421 = BCD. לא כל סט משקלים מאפשר לייצג את כל 0–9 (למשל 9,4,2,1 לא מייצג 8). יש סטים עם שני ייצוגים לאותה ספרה (2,2,4,1; 6,4,2,−3).
  - **Excess-3:** ספרה + 3 בבינארי. **self-complementing:** היפוך הביטים נותן את המשלים ל-9 (0 = 0011 ↔ 1100 = 9).
  - **קוד Gray:** ספרות עוקבות נבדלות בביט אחד, וגם ציקלי. בינארי → Gray: g_MSB = b_MSB, gᵢ = bᵢ ⊕ bᵢ₊₁. Gray → בינארי: b_MSB = g_MSB, bᵢ = bᵢ₊₁ ⊕ gᵢ. בונים n+1 ביט משיקוף של n ביט (0 לפני המקור, 1 לפני ההיפוך). דוגמאות: (16)₁₀ = (11000)G, (101010)₂ = (111111)G. **הסדר של צירי מפת קרנו הוא קוד Gray.**
  - **מרחק Hamming:** מספר המיקומים שבהם שתי מילים נבדלות, למשל 10101 ו-10011: 2. ביט זוגיות מגלה מספר אי-זוגי של שגיאות בלבד.
  - **כמה מספרים ב-48 ביט:** בינארי 2⁴⁸; BCD 10¹²; ASCII 8 ביט: 128⁶.
  - **ייצוג נקודה:** fixed point (מיקום קבוע) ו-floating point (מנטיסה, מעריך, בסיס). כפל: כופלים מנטיסות ומחברים מעריכים; חיבור: קודם משווים מעריכים.
- **אריתמטיקה בבסיס כלשהו בלי לעבור דרך עשרוני (תרגיל בית 2):** (435)₈ + (267)₈ = (724)₈; (A7D)₁₆ − (3B2)₁₆ = (6CB)₁₆. אלגוריתם המרה 5 → 7 בלי בסיס 10 (תרגיל בית 1, בונוס): מכפילים ב-5 ומחברים ספרה, וכל החשבון נעשה בבסיס 7.
- **Unicode / UTF-8:** 8 עד 32 ביטים לתו, עד 1,112,064 תווים. תואם לאחור ל-ASCII (7 הביטים הראשונים זהים).

### שלוש שיטות לייצוג מספרים מסומנים
| שיטה | שלילי | אפס | טווח ב-n ביטים | חיבור |
|---|---|---|---|---|
| Sign-Magnitude | MSB = סימן (0 חיובי, r−1 שלילי), השאר = ערך מוחלט | שני ייצוגים (+0, −0) | −(2ⁿ⁻¹−1) … 2ⁿ⁻¹−1 | לא עובד עם חיבור רגיל |

- למה SM לא עובד: 1100 (−4) + 0001 (+1) = 1101 = −5, ולא −3.
- גם בבסיס עשרוני: 9's complement של 0631 = 9368; 10's complement של 0654 = 9345+1 = 9346.
- דוגמה: 12 = 001100, ב-1sc: −12 = 110011, ב-2sc: −12 = 110100.
- **קיצור דרך ל-2sc:** סורקים מימין לשמאל עד ה-1 הראשון (כולל), ומשם הופכים את כל שאר הביטים.
- ההמרה הפיכה: משלים ל-2 של משלים ל-2 מחזיר את המספר המקורי.
- **הרחבת מספר ביטים (sign extension):** ב-1sc וב-2sc משכפלים את ה-MSB (0 לחיובי, 1 לשלילי). ב-SM מכניסים אפסים בין ביט הסימן לשאר הביטים.

### משלים ל-2 (2's complement): דוגמאות
- 13 = 01101, −13 = 10011; 18 = 010010, −18 = 101110.
- (−533)₈ ב-10 ביטים: 533₈ = 0101011011 → הפוך+1 = 1010100101.
- **חיבור:** מרחיבים סימן לאותו אורך, ו**זורקים את ה-carry היוצא**. −13+18: 110011 + 010010 = (1)000101 → 000101 = 5.

- חיסור = חיבור עם המשלים ל-2. לכן לא צריך מעגל חיסור נפרד: משתמשים במחבר.

### גלישה (Overflow)
- קורית כשהתוצאה מחוץ לטווח הייצוג. קורית רק כששני המחוברים באותו סימן והתוצאה בסימן ההפוך. הפתרון: להוסיף ביט.

## 4. אלגברה בוליאנית (שבוע 2)
- אלגברה בוליאנית (George Boole, 1847/1854). Claude Shannon (שנות ה-30) החיל אותה על מעגלי מיתוג: **Switching Algebra** על הקבוצה {0,1} עם AND, OR, NOT.
- **סדר פעולות:** סוגריים → NOT → AND → OR.

### זהויות
| שם | צורת OR | צורת AND |
|---|---|---|
| אדישות (Idempotent) | x+x = x | x·x = x |
| ערכים אדישים | x+0 = x | x·1 = x |
| שולטים | x+1 = 1 | x·0 = 0 |
| חילוף | x+y = y+x | xy = yx |
| קיבוץ | (x+y)+z = x+(y+z) | (xy)z = x(yz) |
| השלמה | x+x' = 1 | x·x' = 0 |
| פילוג | x+yz = (x+y)(x+z) | x(y+z) = xy+xz |
| בליעה (ראשון) | x+xy = x | x(x+y) = x |
| בליעה (שני) / "צמצום" | x+x'y = x+y | x(x'+y) = xy |
| צמצום | xy+xy' = x | (x+y)(x+y') = x |
| היפוך עצמי | (x')' = x | |
| דה-מורגן | (x+y)' = x'y' | (xy)' = x'+y' |

- **דה-מורגן מוכלל:** [f(x₁…xₙ, 0, 1, +, ·)]' = f(x₁'…xₙ', 1, 0, ·, +).
- **דואליות:** מחליפים + ↔ · ו-0 ↔ 1 (בלי להפוך משתנים). f^D = f(x₁…xₙ, 1, 0, ·, +).
- **קונצנזוס:** xy + x'z + yz = xy + x'z; ובצורה הדואלית: (x+y)(x'+z)(y+z) = (x+y)(x'+z).
- **הוכחה בטבלת אמת:** כל פונקציה בוליאנית מוגדרת לחלוטין ע"י טבלת אמת (מספר סופי של הצבות), לכן טבלת אמת היא הוכחה תקפה. דוגמה מההרצאה: (x+y)[x'(y'+z')]' + x'y' + x'z' = 1 (כל השורות בטבלה יוצאות 1).
- XOR: A⊕B = A'B+AB' (בדיקת אי-שוויון, בדיקת זוגיות, חיבור מודולו 2). XNOR = (A⊕B)' = A'B'+AB (בדיקת שוויון).
- כשנותנים g עם שלילה כוללת, הפעילו דה-מורגן על כל הביטוי, ואז פשטו. דוגמה 2023ב: g = (A'+B)·((A'B')⊕(A+A'B)) בהיפוך כולל מצטמצם ל-A'+B' = NAND.

## 5. פונקציות בוליאניות ושלמות פונקציונלית (שבועות 2–3)

### כמה פונקציות יש?
- למשתנה אחד: 2² = 4 פונקציות: קבוע 0, Buffer (x), NOT (x'), קבוע 1.
- לשני משתנים: 2⁴ = 16. באופן כללי ל-n משתנים: 2^(2ⁿ).

| F | 00 01 10 11 (xy) | ביטוי | שם |
|---|---|---|---|
| F0 | 0 0 0 0 | 0 | קבוע 0 |
| F1 | 0 0 0 1 | xy | AND |
| F2 | 0 0 1 0 | xy' | |
| F3 | 0 0 1 1 | x | |
| F4 | 0 1 0 0 | x'y | |
| F5 | 0 1 0 1 | y | |
| F6 | 0 1 1 0 | x⊕y | XOR |
| F7 | 0 1 1 1 | x+y | OR |
| F8 | 1 0 0 0 | (x+y)' = x↓y | NOR |
| F9 | 1 0 0 1 | x⊙y | XNOR |
| F10 | 1 0 1 0 | y' | |
| F11 | 1 0 1 1 | x+y' | |
| F12 | 1 1 0 0 | x' | |
| F13 | 1 1 0 1 | x'+y | |
| F14 | 1 1 1 0 | (xy)' = x↑y | NAND |
| F15 | 1 1 1 1 | 1 | קבוע 1 |

### שלמות פונקציונלית
- קבוצה שלמה אם אפשר לממש בה כל פונקציה. {AND, OR, NOT} שלמה. מספיק להראות אחד מ: NAND, NOR, {AND+NOT}, {OR+NOT}.
- **NAND שלם:** NOT = (xx)'; AND = NOT(NAND); OR = NAND(x', y') (דה-מורגן).
- **NOR שלם:** NOT = (x+x)'; OR = NOT(NOR); AND = NOR(x', y').
- **דוגמה מההרצאה:** f(x,y,z) = x'y' + x'z' + y'z'. f(x,x,x) = x' → NOT. f(x',y',1) = xy → AND. לכן **{f, 1}** שלמה. f לבדה לא שלמה, כי צריך גם לייצר "1".
- **שיטה למבחן:** מציבים קבועים 0/1 (כשמותר) בחלק מהמשתנים כך שיישאר NOT ו-AND (או OR), או ישירות NAND/NOR. כותבים במפורש: f(A,1,0,1) = A' → NOT; f(1,B,C,1) = BC → AND.
- תוצאות שחוזרות במבחנים:
  - **FA עם קבועים: שלם.** S(A,0,1) = A' (NOT), Cout(A,B,0) = AB (AND).
  - **Decoder 2x4 בלי קבועים (חוץ מ-En): שלם.** D0 = X'Y' = (X+Y)' = NOR.
  - **MUX עם הקבועים 0,1: שלם** (נאמר בהרצאה). NOT = MUX(I0=1, I1=0, S=A). כך מקבלים היפוכים כשאין גישה ל-A'.
  - **T-FF יחיד לא יכול לממש XOR** (רכיב סדרתי עם כניסה אחת; ה-XOR שלו הוא בין ערכים בזמנים שונים, T = y⊕Y).
  - **D-FF מ-T-FF + XOR יחיד:** T = D ⊕ Q.
- אם אין קבועים, בודקים אם יש "פונקציה מונוטונית" (רק AND/OR, בלי היפוך): אז היא לא שלמה.

## 6. צורות קנוניות SoP / PoS (שבוע 3B)

### הגדרות
- **ליטרל:** משתנה או המשלים שלו (x, x').
- **Product term:** מכפלת ליטרלים. **מינטרם:** מכפלה שבה כל משתנה מופיע בדיוק פעם אחת. שווה 1 בהצבה אחת בלבד.
- **Sum term:** סכום ליטרלים. **מקסטרם:** סכום שבו כל משתנה מופיע בדיוק פעם אחת. שווה 0 בהצבה אחת בלבד.
- **SoP קנוני:** סכום מינטרמים בלבד. **PoS קנוני:** מכפלת מקסטרמים בלבד.
- **Mᵢ = (mᵢ)'** (דה-מורגן). לדוגמה x'yz' = (x+y'+z)'.

| # | xyz | מינטרם | מקסטרם |
|---|---|---|---|
| 0 | 000 | x'y'z' | x+y+z |
| 1 | 001 | x'y'z | x+y+z' |
| 2 | 010 | x'yz' | x+y'+z |
| 3 | 011 | x'yz | x+y'+z' |
| 4 | 100 | xy'z' | x'+y+z |
| 5 | 101 | xy'z | x'+y+z' |
| 6 | 110 | xyz' | x'+y'+z |
| 7 | 111 | xyz | x'+y'+z' |

שימו לב: במינטרם 0 → משתנה עם גג; במקסטרם 0 → משתנה בלי גג.

### מטבלת אמת לביטוי
- **SoP:** לוקחים את השורות שבהן f=1 ומחברים את המינטרמים שלהן.
- **PoS:** לוקחים את השורות שבהן f=0 ומכפילים את המקסטרמים שלהן. (ההצדקה: f' = Σ של האפסים, ודה-מורגן נותן f = Π.)
- **דוגמת הרמזור (הרצאה):** R, Y, G. תקין: נורה אחת בלבד, או אדום+צהוב יחד. F=1 בשגיאה.
  F = Σm(0,3,5,7) = R'Y'G' + R'YG + RY'G + RYG = ΠM(1,2,4,6) = (R+Y+G')(R+Y'+G)(R'+Y+G)(R'+Y'+G).
  (בדיקה: 000 = כלום דולק → שגיאה; 011, 101, 111 = ירוק עם עוד נורה → שגיאה.)

### מביטוי מצומצם לקנוני
- מכפילים כל מכפלה ב-(v+v') לכל משתנה v שחסר בה, פותחים סוגריים ומוחקים כפילויות.
  F = R'Y'G' + RG + YG = R'Y'G' + RG(Y+Y') + YG(R+R') = R'Y'G' + RYG + RY'G + R'YG.
- את ה-PoS הקנוני הכי פשוט למצוא דרך ה-SoP: המקסטרמים הם כל המספרים שלא הופיעו ב-Σ.
- דוגמאות מהמבחנים: f = Σ(1,3,4,6) = AC'+A'C = A⊕C; PoS: Π(0,2,5,7) = (A+B+C)(A+B'+C)(A'+B+C')(A'+B'+C'). 2025ג: f(x,y,z) = Π(0,2,6,7) = x'z + xy'.

### תובנות
- הצורה הקנונית **יחידה**, אבל לא בהכרח מינימלית (יותר שערים ו-fan-in גבוה יותר).
- למה צריך את שתיהן: **SoP → קל לממש ב-NAND בלבד. PoS → קל לממש ב-NOR בלבד.** בפועל SoP נפוץ יותר.
- **"המתכון" ל-NAND בלבד:** שמים שלילה כפולה על כל הביטוי, ומפעילים דה-מורגן שוב ושוב עד שמגיעים לביטוי של NAND בלבד. לדוגמה xy + zw = ((xy)'·(zw)')' = NAND(NAND(x,y), NAND(z,w)). ל-NOR בלבד אותו דבר על PoS.
- NOT מ-NAND/NOR: מחברים את שתי הכניסות יחד.

## 8. מינימיזציה ומפות קרנו (שבוע 4B)

### מטרה
- למצוא ביטוי שקול ל-f (אותה פונקציונליות) עם **מספר מינימלי של מכפלות**, ובתוכן **מספר מינימלי של ליטרלים**.
- המדדים: q_f = מספר המכפלות (מינטרמים) בביטוי, p_f = מספר הליטרלים.
- הסיבה: פחות רכיבים → פחות שטח (Die area, mm²) ופחות הספק (TDP, W). אלה שני הפרמטרים החשובים ביותר בתכנון מעבדים. יש trade-off: הקטנת הספק פוגעת במהירות.
- **אין "מרשם" לביטוי מינימלי, והוא לא בהכרח יחיד.** ביטוי שאי אפשר לצמצם עוד הוא לא בהכרח מינימלי.

### שלוש שיטות
1. **זהויות אלגבריות:** עובד תמיד, אבל מסורבל.
2. **מפות קרנו:** גרפי ופשוט, עד 4 משתנים (אפשר עד 6, אבל לא מעשי).
3. **Quine-McCluskey:** אלגוריתם כללי לכל מספר משתנים, ניתן לתכנות. **לא במבחן.**

### בניית המפה
- הצירים מסודרים ב**קוד Gray** (מרחק Hamming 1 בין שכנים): 00, 01, 11, 10.
- 3 משתנים: x2 בשורות, x1x0 בעמודות. 4 משתנים: x3x2 בשורות, x1x0 בעמודות.
- מספור המשבצות (4 משתנים): שורה 00: 0,1,3,2; שורה 01: 4,5,7,6; שורה 11: 12,13,15,14; שורה 10: 8,9,11,10.
- **שכנות:** שתי משבצות שכנות אם הן נבדלות בביט אחד. לכל משבצת יש N שכנים (N = מספר המשתנים). **המפה ציקלית** (הקצוות שכנים): במפת 3 משתנים השכנים של 1 הם 0,3,5, והשכנים של 2 הם 0,3,6.

### כללי קיבוץ
- מסמנים קבוצות של משבצות 1 שכנות. **גודל קבוצה = חזקה של 2** (1, 2, 4, 8...). חובה לכסות את כל ה-1.
- סדר עדיפויות:
  1. קבוצות גדולות ככל האפשר.
  2. כמה שפחות קבוצות.
  3. להימנע מכיסוי כפול (העדיפות הכי נמוכה: כיסוי כפול מותר אם הוא מגדיל קבוצה).
- **כתיבת המכפלה של קבוצה:** רושמים רק משתנים שערכם קבוע בכל המשבצות בקבוצה (1 → x, 0 → x'). משתנה שמשתנה מצטמצם: x2'x1x0' + x2x1x0' = x1x0'(x2+x2') = x1x0'.
- **הגדרות:** קבוצה של מינטרמים = **אימפליקנט**. **אימפליקנט ראשי (PI)** = אימפליקנט מקסימלי שאי אפשר להגדיל. **אימפליקנט חיוני (EPI)** = PI שמכסה מינטרם שאף PI אחר לא מכסה. EPI חייב להופיע בביטוי המינימלי.
- דוגמה מההרצאה: F = Σ(2,4,5,6,7) → F = x2 + x1x0'.
- **PoS עם מפת קרנו:** מקבצים את ה-0 (מקבלים את f' כ-SoP), ואז דה-מורגן.

### "חידת טבלת האימפליקנטים" (שאלה 2א בכל מבחן)
- נתון: f = Σ(חלק מהמינטרמים, ?, ?) + Σd(?), וטבלה: שורות = אימפליקנטים ראשיים (מספר ה-? = מספר הליטרלים), עמודות = מינטרמים עם X.
- **שיטה:** אימפליקנט עם k ליטרלים (מתוך 4) מכסה 2^(4−k) משבצות. מתחילים מהשורה שיש בה הכי הרבה X ידועים, מוצאים איזה מלבן במפה מכסה בדיוק אותם, ומשלימים. פותרים A.1 ו-A.2 יחד (גם המבחן ממליץ על זה).
- לפעמים יש כמה מילויים נכונים (בחירת ה-don't care). כל מילוי שעומד בתנאים מתקבל.
- דוגמאות פתורות:
  - 2023א: f = A'C' + AC + B'D' + BD.
  - 2022א: f = CD + B'D' (או A'D + B'D').
  - 2023ב: f = A'B + AC + AD' (או A'B + AC + CD').
  - 2024א: f = A'C + CD + A'BD + AB'D (6 הוא don't care).
  - 2024ב: f = B'C' + C'D + A'BD + A'B'D'.
  - 2025ב: f = A'B'C' + BC + BD'.
  - 2025ג: f = AB' + C'D' + A'BC.

## 9. Fan-in, רמות, השהיה ו-Hazards (שבוע 5)

### מגבלת Fan-in
- כשמוגבלים ל-fan-in קטן (למשל 2), מפרקים שער גדול לעץ של שערים קטנים: x0x1x2 → (x0x1)·x2. כדאי להוציא גורם משותף כדי לחסוך שערים.
- דוגמה מההרצאה: f = Σ(7,8,9,12,13,14,15) = x3x1' + x3x2 + x2x1x0. עם fan-in 2: f = x1'x3 + x2(x3 + x1x0).
- **מגבלות fan-in נשמרות במעבר ל-NAND-NAND או ל-NOR-NOR** (המבנה זהה, רק סוג השער משתנה).

### רמות (Levels) והשהיה (Delay)
- לכל שער יש זמן השהיה t_p (בגלל המימוש הפיזי). ההשהיה של מעגל = ההשהיה של **המסלול הקריטי**, כלומר המסלול האיטי ביותר מכניסה ליציאה.
- דוגמה מההרצאה (T_NOT = 1ns, T_AND = 2.5ns, T_OR = 2ns): מחשבים את סכום ההשהיות בכל מסלול בנפרד (OR+AND+OR+AND = 9ns, OR+AND = 4.5ns, OR+AND+NOT = 5.5ns...). ההשהיה של המעגל = המקסימום = 9ns.
- **השהיה מינימלית של עץ:** כדי לחבר N כניסות עם שערים בעלי fan-in נתון צריך לפחות ⌈log_{fan-in} N⌉ רמות. כלומר השהיה מינימלית = ⌈log_{fan-in}(N)⌉ · t_p. לדוגמה, AND של 16 כניסות עם fan-in 2: log₂16 = 4 רמות → 4·t_p.
- SoP/PoS בצורה דו-רמתית: 2 רמות (3 עם המהפכים בכניסה).

### Hazards (מפגעים)
- **Static hazard:** הפלט אמור להישאר קבוע (למשל 1), אבל בגלל השהיות שונות במסלולים הוא קופץ לרגע ל-0 וחוזר (glitch).
- דוגמה מההרצאה: F = X0X1 + X1'X2, עם X0=X2=1. כש-X1 עובר 1→0, המכפלה X0X1 נופלת לפני ש-X1'X2 עולה (יש השהיה במהפך של X1), ו-F יורד ל-0 לרגע.
- **התיקון:** מוסיפים את איבר הקונצנזוס שמכסה את המעבר בין שתי הקבוצות במפת קרנו: F = X0X1 + X1'X2 + **X0X2**. (במספור x2x1x0: F = Σ(3,4,5,7). X0X1 מכסה את 3,7, X1'X2 מכסה את 4,5, ו-X0X2 מכסה את 5,7, כלומר את המעבר ביניהן.) האיבר מיותר מבחינה לוגית, אבל מבטל את ה-hazard.
- **כלל אצבע:** hazard סטטי ב-SoP קיים כששתי קבוצות במפת קרנו נוגעות זו בזו בלי קבוצה שמכסה את המעבר ביניהן.
- מהמבחן (2025ב): X NAND X' שווה תמיד 1 כשאין השהיה, אבל עם השהיה במהפך נוצרים קוצים ברוחב ההשהיה בכל מעבר של X.

## 10. מחברים (Adders) (שבוע 6A)
- "חשיבה במודולים": בונים רכיבים מורכבים מאבני בניין קטנות.

### Half Adder (HA)
- מחבר שני ביטים: S = A⊕B = A'B + AB', C = AB.

### Full Adder (FA)
- מחבר שלושה ביטים (כולל Cin): S = A⊕B⊕Cin = Σ(1,2,4,7); Cout = AB + Cin(A⊕B) = Σ(3,5,6,7) (פונקציית רוב/majority).
- מימוש יעיל: מחשבים את A⊕B פעם אחת ומשתמשים בו גם ל-S וגם ל-Cout.
- **FA משני HA ושער OR:** HA ראשון על A,B נותן A⊕B ו-AB. HA שני על (A⊕B),Cin נותן S = A⊕B⊕Cin ו-Cin(A⊕B). Cout = AB + Cin(A⊕B).

### מחבר רב-ביטי (Ripple Carry)
- שרשור n יחידות FA, ה-Cout של כל אחת נכנס ל-Cin של הבאה. Cin של הראשונה = 0. בדיקה 2022: 0011+1011 = 1110.
- **החיסרון: השהיה מצטברת.** ה-carry צריך "לעבור" דרך כל ה-FA, וההשהיה גדלה לינארית עם מספר הביטים.

### Carry Look-Ahead Adder (CLA) — 🚫 לא במבחן השנה (להעשרה בלבד)
- מגדירים לכל ביט: **Pᵢ = Aᵢ⊕Bᵢ** (propagate: מעביר carry אם יש) ו-**Gᵢ = AᵢBᵢ** (generate: מייצר carry בעצמו).
- Sᵢ = Pᵢ ⊕ Cᵢ, C_{i+1} = Gᵢ + PᵢCᵢ.
- פורשים את הנוסחה כך שכל carry תלוי רק בכניסות ובCin₀:
  - C₁ = G₀ + P₀C₀
  - C₂ = G₁ + P₁G₀ + P₁P₀C₀
  - C₃ = G₂ + P₂G₁ + P₂P₁G₀ + P₂P₁P₀C₀
  - C₄ = G₃ + P₃G₂ + P₃P₂G₁ + P₃P₂P₁G₀ + P₃P₂P₁P₀C₀
- בלי מגבלת fan-in כל carry מחושב ב-2 רמות (אחרי P,G), ולכן ההשהיה כמעט לא תלויה במספר הביטים. המחיר: הרבה יותר שערים ו-fan-in גבוה.
- המשמעות של P ו-G: A=B=0 → אין carry ואין העברה. בדיוק אחד מהם 1 → P=1, carry עובר רק אם הגיע. A=B=1 → G=1, נוצר carry.

### שימושים נוספים ב-FA
- **כפל שני מספרים של 2 ביטים** (x1x0 · y1y0): מכפלות חלקיות ב-AND: x0y0, x1y0, x0y1, x1y1. S0 = x0y0; את השאר מחברים עם מחברים (כמו כפל ארוך בעשרוני): S1 = x1y0 + x0y1, עם ה-carry ל-S2 וכן הלאה.
- **חיסור:** אין צורך במעגל נפרד. מייצגים במשלים ל-2, מחברים, ומתעלמים מה-carry.

### מהמבחנים
- Cout של FA = "A+B+C ≥ 2". "A+B+C = 2" = Cout·S' (MUX2:1: S כבורר, I0 = Cout, I1 = 0).
- FA עם Decoder 3x8 + 2 OR: S = D1+D2+D4+D7, Cout = D3+D5+D6+D7.
- S של FA עם שני Decoder 2x4 + 2 OR(fan-in 2): Decoder ראשון (A,B): D1+D2 = A⊕B; מזינים אותו עם Cin לשני: D1+D2 = A⊕B⊕Cin.
- **שאלת עלות (2022):** מימוש קנוני ב-NAND: 9 NAND + 3 NOT = 21$ (NAND = 2$, NOT = 1$). מימוש עם XOR: S = A⊕B⊕Cin, Cout = ((Cin(A⊕B))'·(AB)')' → 2 XOR + 3 NAND = 2x+6. כדאי כש-2x+6 < 21, כלומר XOR < 7.5$.

## 11. מרבב (MUX) (שבוע 6B)

### הגדרה
- MUX 2ⁿ:1 בוחר אחת מ-2ⁿ כניסות נתונים לפי n קווי בחירה (select). סה"כ 2ⁿ + n כניסות ויציאה אחת.
- שימושים: גישה לזיכרון לפי כתובת, ניתוב נתונים ברשתות, מימוש כל פונקציה צירופית ("מעבד של עניים").
- MUX 4:1: f = S1'S0'·I0 + S1'S0·I1 + S1S0'·I2 + S1S0·I3, כלומר f = Σ mᵢ·Iᵢ (mᵢ = מינטרם של קווי הבחירה).
- MUX 2:1: f = S'·I0 + S·I1.

### מימוש
- **ישיר (דו-רמתי):** OR עם fan-in = 2ⁿ, ו-2ⁿ שערי AND עם fan-in = n+1. תמיד 2 רמות השהיה (3 כולל מהפכים לקווי הבחירה), אבל ה-fan-in גדל עם n.
- **רקורסיבי מ-MUX 2:1:** עץ של MUX 2:1. שומר על fan-in ≤ 2, אבל ההשהיה גדלה עם n. (MUX 4:1 = 3 × MUX 2:1: שניים ברמה הראשונה עם S0, אחד ברמה השנייה עם S1.)

### MUX כמעגל צירופי כללי
- MUX + הקבועים 0,1 = מערכת שלמה, ובנוסף אפשר לממש כל פונקציה בקלות. לפונקציה של n משתנים:
  - **MUX 2ⁿ:1** עם כל המשתנים בבוררים: הכניסות הן ערכי טבלת האמת (0/1). בלי שערים בכלל.
  - **MUX 2ⁿ⁻¹:1 + מהפכים:** n−1 משתנים בבוררים, כל כניסה ∈ {0, 1, x, x'} של המשתנה הנותר (מחלקים את טבלת האמת לזוגות).
  - **MUX 2ⁿ⁻²:1 + שערים עם fan-in ≤ 2:** כל כניסה היא פונקציה של שני המשתנים הנותרים.
- **דוגמה מההרצאה:** F(x3,x2,x1,x0) = Σ(0,1,3,6,7,8,11,12,14).
  - MUX 16:1: I0,I1,I3,I6,I7,I8,I11,I12,I14 = 1, השאר 0.
  - MUX 8:1 (S = x3x2x1, משתנה נותר x0): I0=1, I1=x0, I2=0, I3=1, I4=x0', I5=x0, I6=x0', I7=x0'.
  - MUX 4:1 (S = x3x2, נותרים x1x0): I0 = x1'+x0 (מינטרמים 0,1,3), I1 = x1 (6,7), I2 = x1⊙x0 (8,11), I3 = x0' (12,14).
- **שיטת ההרחבה (Shannon):** f = A'·f(A=0) + A·f(A=1). לדוגמה 2023א: f = A'(B'C) + A(B+C) → MUX עם S=A. חוזרים על זה עם MUX פנימיים.
- **DEMUX** הוא הפעולה ההפוכה: כניסה אחת מנותבת לאחת מ-2ⁿ יציאות. Decoder יכול לשמש כ-DEMUX (שבוע 7).

### דוגמאות מהמבחנים
- **Cout של מחבר 2 ביט (A1A0 + B1B0):** Cout=1 במינטרמים 7,10,11,13,14,15 (סדר A1A0B1B0).
  - MUX16:1: I7, I10, I11, I13, I14, I15 = 1, השאר 0.
  - MUX4:1 עם S1S0 = A1A0: I0 = 0, I1 = B1B0, I2 = B1, I3 = B1+B0.
  - עם Cin: חלק מהכניסות הופכות ל-Cin (מקרים שבהם הסכום בדיוק 3).
- MUX4:1 משערים בלבד (fan-in ≤ 2): מינטרמים של S1,S0 (עם NOT), AND עם כל Iᵢ, עץ OR. אפשרי כי MUX הוא צירופי.
- MUX4:1 מ-Decoder 2x4 + AND/OR: כל יציאת Decoder (Dᵢ) עושה AND עם Iᵢ, ואז OR.
- MUX8:1 משני Decoder 2x4 + מהפך: בונים Decoder 3x8 (ה-MSB ל-En של אחד, ההופכי שלו ל-En של השני) וממשיכים כמו קודם.
- 2024ב: k עם 4 MUX2:1 בלי שערים: "MUX4:1" מ-3 MUX2:1 (S = Y, A), כניסות 0, B, 0, B'C, ואת B'C מייצרים ב-MUX רביעי (S=B, I0=C, I1=0).
- 2024א: f עם MUX4:1 (S=A,B) + AND + OR: I0 = C, I1 = C+D, I2 = D, I3 = CD.

## 12. Decoder ו-Encoder (שבוע 7A)
- שימושים: ממשקי DAC/ADC, גישה לזיכרון (יחד עם MUX), מימוש כל פונקציה בוליאנית.
- סוגים: Decoder n×2ⁿ (1x2, 2x4, 3x8...), Encoder 2ⁿ:n (2:1, 4:2, 8:3...).

### Decoder (מפענח)
- n כניסות + En, 2ⁿ יציאות. **Dᵢ = En·mᵢ** (המינטרם ה-i של הכניסות). כש-En=0 כל היציאות 0.
  - 1x2: D0 = En·x1', D1 = En·x1. 2x4: D0 = En·x2'x1', D1 = En·x2'x1, D2 = En·x2x1', D3 = En·x2x1.
- יש גרסאות עם כניסות/יציאות **Active Low** (מסומנות בעיגול, פעילות ב-0).
- אפשר לבנות Decoder גדול מקטנים + מהפכים, רקורסיבית (ה-MSB קובע איזה Decoder מקבל En).
- **מימוש פונקציה:** כל פונקציה = OR של יציאות ה-Decoder של המינטרמים שלה. דוגמה מההרצאה: F = Σ(0,1,3,6,7,8,11,12,14) עם Decoder 4x16 = OR של D0,D1,D3,D6,D7,D8,D11,D12,D14. עם fan-in ≤ 2: עץ של 8 שערי OR2.
- **Decoder = DEMUX:** מכניסים את אות הנתונים ל-En, וקווי הבחירה לכניסות הרגילות. האות מנותב ליציאה הנבחרת.
- מהמבחנים:
  - **Decoder 4x16 משני 3x8:** A ל-En של העליון (מינטרמים 8–15), A' ל-En של התחתון (0–7). את A' מייצרים עם MUX2:1 (I0=1, I1=0, S=A) אם אין NOT.
  - מימוש g = B + AC' + A'DC עם Decoder 3x8 (D,C,A) + OR יחיד: OR של היציאות המתאימות, ו-B נכנס ישירות ל-OR.
  - **Decoder 2x4 בלי קבועים שלם פונקציונלית:** D0 = X'Y' = NOR.
  - MUX4:1 מ-Decoder 2x4 + AND + OR: Dᵢ·Iᵢ לכל i ואז OR. (2022ב: g ממומש כך עם S1=C, S0=D', I0=A, I1=B, I2=A, I3=B'.)

### Encoder (מקודד)
- הפעולה ההפוכה: 2ⁿ כניסות שבדיוק אחת מהן 1 → n ביטים שמקודדים את המספר שלה. Encoder 8x3: x3 = D4+D5+D6+D7, x2 = D2+D3+D6+D7, x1 = D1+D3+D5+D7 (D0 לא מחובר בכלל). עם En: AND של En עם כל יציאה.
- הטבלה המלאה היא 2⁸ = 256 שורות; כל מה שאינו "בדיוק כניסה אחת דולקת" הוא don't care.
- **הבעיה:** אם יותר מכניסה אחת דולקת (רעש, תקלה), הפלט לא מוגדר.
- **Priority Encoder:** מתחשב רק בכניסה הגבוהה ביותר שדולקת. בטבלה שלו ה-don't care נמצאים **בצד המשתנים**, לא בצד הפלט.
  - כלל: d בצד הכניסות = אפשר להתעלם מהמשתנה הזה בשורה (הוא מצטמצם: a0'a1'(a2+a2') = a0'a1').
  - x3 = D7 + D6 + D5 + D4 (אחרי בליעות)
  - x2 = D7 + D6 + D3D4'D5' + D2D4'D5'
  - x1 = D7 + D5D6' + D3D4'D6' + D1D2'D4'D6'

## 13. Latches (שבוע 7B)
- **Latch** = רכיב זיכרון בסיסי ששומר ביט אחד. הדוגמה הראשונה למעגל שהיציאה שלו מחוברת חזרה לכניסה.
- **ההבדל בין Latch ל-Flip-Flop:** FF מתעדכן לפי שעון חיצוני; Latch מתעדכן מיד (לפי השהיות השערים). המימוש הבסיסי זהה.
- **ניתוח מעגלים עם משוב:** בודקים לאיזו כניסה השער "רגיש". NOR רגיש ל-1 (כניסה 1 → יציאה 0 בלי קשר לשנייה). NAND רגיש ל-0 (כניסה 0 → יציאה 1).
- **שתי טבלאות לכל Latch/FF:**
  - **טבלה אופיינית (Characteristic):** בהינתן הכניסות והמצב הנוכחי, מה המצב הבא. **לניתוח.**
  - **טבלת עירור (Excitation):** בהינתן מעבר Q(t)→Q(t+1), אילו כניסות צריך. **לתכנון.**

### SR Latch (שני NOR מוצלבים)
| S | R | Q(t+1) |
|---|---|---|
| 0 | 0 | Q(t) (שמירה) |
| 0 | 1 | 0 (Reset) |
| 1 | 0 | 1 (Set) |
| 1 | 1 | אסור (Q = Q' = 0) |

- משוואה אופיינית: Q(t+1) = S + R'Q(t) (בהנחה ש-SR = 0).
- **Gated Latch:** מוסיפים כניסת En. כש-En=0 ה-Latch "קפוא".

### D Latch
- כניסה אחת: S = D, R = D'. כך אי אפשר להגיע ל-S=R=1. **Q(t+1) = D.**
- בלי En זה סתם השהיה. עם En (Gated D Latch): כש-En=0 שומרים את המצב. זה הבסיס לעבודה עם שעון.

### T Latch
- מבוסס על D Latch עם D = T ⊕ Q. **Q(t+1) = T ⊕ Q(t)**: T=0 שומר, T=1 הופך (Toggle). שימושי מאוד במונים.

### JK Latch
- משלב SR ו-T: כשהכניסות "חוקיות" מתנהג כמו SR (J=Set, K=Reset), וב-J=K=1 הופך (במקום מצב אסור).
- תוכנן מתוך טבלת העירור של SR (זו הדוגמה הראשונה לתכנון בקורס): **S = JQ', R = KQ**.
- **Q(t+1) = JQ' + K'Q.** J=K=0 שומר, J=K=1 הופך.

### סיכום: משוואות אופייניות
| FF | Q⁺ |
|---|---|
| D | D |
| T | T ⊕ Q |
| JK | JQ' + K'Q |
| SR | S + R'Q (אסור S=R=1) |

### טבלאות עירור (Q → Q⁺)
| מעבר | D | T | J K | S R |
|---|---|---|---|---|
| 0→0 | 0 | 0 | 0 d | 0 d |
| 0→1 | 1 | 1 | 1 d | 1 0 |
| 1→0 | 0 | 1 | d 1 | 0 1 |
| 1→1 | 1 | 0 | d 0 | d 0 |

- ל-D ול-T יש נוסחה ישירה: **D = Y**, **T = Y ⊕ y** (Y = מצב הבא, y = מצב נוכחי).

### המרות בין FF
- T מ-JK: J = K = T.
- T מ-D: D = T ⊕ Q (שער XOR יחיד). D מ-T: T = D ⊕ Q.
- JK מ-SR: S = JQ', R = KQ.
- **טעינת ערך Xᵢ ל-JK (2022ב):** J = Xᵢ, K = Xᵢ'. (שמירה: J=K=0; היפוך: J=K=1.)
- **SR → JK באותו תכנון (2024א):** עובד, כי תכנון SR אף פעם לא נותן S=R=1 (המצב היחיד שבו JK מתנהג אחרת). מתכנון מראש עם JK אפשר לקבל מעגל פשוט יותר כי יש יותר don't cares.

## 14. תזמון, שעון ו-Flip-Flops (שבוע 8A)

### הגדרות זמן
- t_p = ½(t_pHL + t_pLH): ממוצע זמני ההשהיה במעבר 1→0 ו-0→1. (t_pHL ו-t_pLH יכולים להיות שונים, וזה יוצר בעיות תזמון במערכות אסינכרוניות.)
- **t_cd (Contamination Delay):** הזמן מתחילת השינוי בכניסה שבו מובטח שהיציאה עוד לא השתנתה. בקורס מניחים t_cd = 0.
- **t_pd (Propagation Delay):** הזמן מסוף השינוי בכניסה עד שהיציאה מתייצבת. אצלנו זה t_p.
- **T_setup / T_hold:** הכניסה צריכה להיות יציבה T_setup לפני אירוע השעון ו-T_hold אחריו. בקורס מאחדים הכול ל-t_p.

### שעון
- במעגלים גדולים אי אפשר להבטיח פעולה נכונה בלי שעון. **שעון** = גל ריבועי מחזורי בתדר קבוע.
- T = T_H + T_L (מחזור), f = 1/T, **Duty Cycle** D.C = T_H/T (לא תמיד 50%).
- מערכות מורכבות משתמשות בשעון בסיס וכפולות שלו, כדי שהכול יישאר מסונכרן.

### סוגי הפעלה
- **Level Triggered:** ה-FF מתעדכן כל עוד השעון ברמה מסוימת (High או Low). זה בעצם Gated Latch שה-En שלו מחובר לשעון. החיסרון: כל זמן הרמה המעגל מתנהג כאילו אין שעון.
- **Edge Triggered:** מתעדכן רק ברגע עליית השעון (Positive Edge) או ירידתו (Negative Edge). מסומן במשולש ליד כניסת השעון.
- **Master-Slave:** המימוש הנפוץ ל-Edge Triggered. שני FF מסוג Level Triggered בטור, עם שעון הפוך ביניהם. Master פעיל ב-High ו-Slave ב-Low → Negative Edge Triggered. כדי לקבל Positive Edge הופכים את השעון.
  - 2020: אם חסרים D-FF, אפשר לבנות אותם משערים בשיטת Master-Slave.
- **מעגל סינכרוני:** כל הכניסות הסינכרוניות מקבלות את אותו שעון.

### כניסות אסינכרוניות
- כניסות איפוס/קביעה (CLR, PRE) שפועלות בלי קשר לשעון. משמשות לקבוע מצב התחלתי ידוע בהדלקה. **כניסות איפוס תמיד אסינכרוניות.** בדרך כלל Active Low (עיגול בכניסה).

### שימושים ב-FF
1. מונים. 2. אוגרים (רכיבי זיכרון בסיסיים). 3. שמירת מצב ב-FSM. 4. בסיס לחלק ממערכי הזיכרון (SRAM).

### דיאגרמות זמנים (שרשרת FF, מהמבחנים)
- כל FF מגיב בעליית שעון לפי הערכים **רגע לפני** העלייה. מחשבים מצב-אחרי-מצב בטבלה ואז מציירים.
- 2024א (T, D, T, כניסה 1): Q2Q1Q0 עובר 001, 010, 101, 110, 001... מינימום 1, מקסימום 6.
- 2024ב (JK, D, T): מחזורי, 001, 110, 101, 010, סכום ערכים במחזור = 14.
- 2025א (4 JK + 2 AND, J=K מהשרשרת של Q'): **מונה מטה** 0000 → 1111 → 1110 → 1101 → …

### ⭐ דיאגרמות זמנים עם Tp מפורש (מבחני 2026; מעגלי בדיקה TC-T1–T3)
**הכללים שהפתרונות הרשמיים מראים:**
1. ה-FF **דוגם את הכניסה רגע לפני עליית השעון** ("The sampling is always just before the clk change", 2026ב). אם כניסה משתנה בדיוק ברגע העלייה, נדגם הערך הישן.
2. היציאה של FF משתנה ב-Tp(FF) אחרי העלייה. היציאה של שער משתנה ב-Tp(שער) אחרי שינוי כניסה. כל פולס עובר (transport).
3. "CLK switches its state every 1 second" = מחזור של 2s. העליות ב-t = 1, 3, 5…
4. המצב ההתחלתי נתון ועקבי (למשל Q0=0, Q1=Q0'=1).
- **2026א 2D:** T-FF (T=1) → מהפך → Q1; Q2 = AND(Q1, Q0'). Tp(FF)=0, Tp(שערים)=0.5 → Q2 הוא פולס ברוחב 1.5s בין t=4 ל-5.5, ולא ברוחב 2s כמו Q0'. כשגם ל-FF יש Tp=0.5: "אותו גרף, מוזז".
- **2026ב 2D:** J = K = NOT(CLK) דרך שני מהפכים, JK-FF, Q=0, J=K=1. Tp=0 → Q מתהפך בכל עלייה. Tp(inv)=0.5, Tp(FF)=1 → מתהפך באיחור של 1s. Tp=1 לכולם → אחרי המחזור הראשון ה-FF תמיד דוגם J=K=0, ו-**Q נשאר 1**.
- **2026ג 2D:** D-FF, D = Q' דרך שני מהפכים, Q1 = NOT Q. Tp=0 → מחלק תדר ב-2. Tp(inv)=1 → D משתנה בדיוק בעליית השעון, ולכן המחזור מתארך ל-8s.
- **קבוצה C (שאלה 4):** 2026א: 3 D-FF בטבעת עם מהפך (מונה Johnson); עובד כל עוד Tp(inv) < T_clk. 2026ב: 3 T-FF + מהפך, מהתחלה 000 ומהתחלה 111.

## 15. מונים ואוגרים (שבוע 8B)

### Ripple Counter (מונה אסינכרוני)
- שרשרת T-FF עם T=1. השעון נכנס רק ל-FF הראשון (LSB), והיציאה Q' של כל FF היא השעון של הבא. → סופר למעלה. אם משתמשים ב-Q כשעון לשלב הבא → סופר למטה.
- Q0 מתחלף כל מחזור, Q1 כל 2, Q2 כל 4, Q3 כל 8: 0, 1, 2, ..., 15, 0.
- **חיסרון:** ההשהיה גדלה לינארית עם מספר הביטים (כל FF מחכה לקודם).

### Synchronous Counter (מונה סינכרוני)
- כל ה-FF מקבלים את אותו שעון, ולכן ההשהיה לא תלויה במספר הביטים. המימוש מורכב יותר.
- מונה בינארי עם T-FF: T0 = 1, T1 = Q0, T2 = Q0Q1, T3 = Q0Q1Q2 (ביט מתהפך כשכל הביטים שמתחתיו 1).
- 2022ב: עם שני T-FF והשעון כ-T: T1 = 1, T2 = y1 → X2X1 סופר 00, 01, 10, 11. כך מייצרים קלט שגורם ל-FSM להוציא Z מחזורי.
- מונה הוא בעצם FSM (2025ב: מונה 3 ביט = 8 מצבים, X=1 סופר, X=0 עוצר).

### מונה בבסיס כלשהו
- לוקחים מונה בינארי שטווח הספירה שלו מכיל את הבסיס הרצוי, ושיש לו כניסת CLR אסינכרונית.
- דוגמה, מודולו 6 עם מונה 4 ביט: כשהמונה מגיע ל-6 (0110) מפעילים CLR. CLR (Active Low) = NAND(Q2, Q1). המצב 6 מופיע לרגע קצר בלבד ומיד מתאפס ל-0.

### אוגרים (Registers)
- **Parallel Register:** n FF שנטענים יחד, עם כניסות Load ו-Clear.
- **Shift Register:** שרשרת D-FF, כל FF מקבל את היציאה של הקודם. הנתון זז מקום אחד בכל מחזור.
- **Register עם Enable:** Enable Output דרוש כדי לחבר כמה אוגרים לאותו BUS (רק אחד כותב בכל רגע).
- **Universal Register:** אוגר שמאפשר טעינה מקבילית, הזזה ימינה/שמאלה ושמירה, לפי קווי בחירה (בדרך כלל MUX 4:1 לפני כל FF).
- מהמבחנים: shift register **לא** יכול להחליף FSM שצריך לדעת איפה מתחילה כל מילה (2023א), אבל כן יכול לשחזר FSM שזוכר את k הכניסות האחרונות (2024ב).
- **העשרה (🚫 לא במבחן):** טרנזיסטור MOSFET (Gate מתכת, Oxide, Source/Drain מסוג N+ על מצע P), סימום עם בורון (P) וזרחן/ארסן (N).

## 16. FSM: מכונת מצבים סופית (שבוע 9)

### הגדרות
- **מעגל סדרתי** = מעגל צירופי + זיכרון ששומר "מצב" (היסטוריה). המוצא תלוי בכניסה ובמצב: Z = f(X, S), והמצב הבא NS = g(X, S). (במעגל צירופי Z = f(X) בלבד.)
- **FSM** = מעגל סדרתי עם מספר סופי של מצבים.
- הגדרה פורמלית: קבוצת K מצבים S = {s₁…s_K} (אחד מהם התחלתי), J כניסות בינאריות, M יציאות בינאריות, **פונקציית מעבר** (מצב + כניסה → מצב הבא) ו**פונקציית מוצא** (מצב + כניסה → מוצא).
- **מספר ה-FF הנדרש = ⌈log₂ K⌉.** כל FF שומר ביט אחד של המצב.
- **Mealy:** המוצא תלוי במצב ובכניסה (כותבים X/Z על הקשתות). **Moore:** המוצא תלוי רק במצב (אפשר לכתוב אותו בתוך עיגול המצב). אפשר לעבור ביניהן (בד"כ ע"י שכפול מצבים), אבל לא בקורס.
  - Moore עדיף במערכות מורכבות ועם כניסות אנלוגיות לא יציבות.
  - **זיהוי בניתוח:** אם עמודות המוצא זהות לכל ערכי הכניסה, זו מכונת Moore; אחרת Mealy.
- דוגמת המנעול (קוד 803): A = התחלה, B = הוקלד 8, C = הוקלד 80. 3 ב-C → Z=1 (פתוח). כל ספרה שגויה → חזרה.

### "המתכון"
**תכנון (מלמעלה למטה) / ניתוח (מלמטה למעלה):**
1. תיאור מילולי
2. דיאגרמת מצבים ו/או טבלת מצבים
3. צמצום מצבים (אופציונלי; 🚫 **לא במבחן השנה**)
4. טבלת הקצאת מצבים (קידוד בינארי)
5. טבלת מעבר (= טבלת מצב הבא + טבלת אמת של המוצא)
6. פונקציית המעבר + פונקציית המוצא
7. משוואות עירור של ה-FF
8. ציור המעגל

### ניתוח (דוגמה מההרצאה, JK + D)
1. מהציור: J = xy₂, K = x + y₂', D = x'y₂' + y₁'y₂, z = xy₁y₂'.
2. מציבים במשוואות האופייניות: Y₁ = Jy₁' + K'y₁, Y₂ = D. מקבלים Y₁ = xy₁'y₂ + x'y₁y₂, Y₂ = x'y₂' + y₁'y₂.
3. טבלת מצב הבא + מוצא (עמודות לכל ערך של x), מחליפים קודים בשמות (00=a, 01=b, 10=c, 11=d).
4. דיאגרמת מצבים, מתחילים מהמצב ההתחלתי (בדרך כלל 00).
5. **תיאור מילולי:** מריצים כמה רצפי קלט מהמצב ההתחלתי. **אורך הרצף ≥ מספר המצבים**, כי כל ביט גורם למעבר אחד לכל היותר. התוצאה בדוגמה: המכונה מזהה את הרצף 0101 (a→b→d→c→z=1), גם אחרי קלט שרירותי.

### תכנון (דוגמת הבמבה מההרצאה)
- חיישן X=1 כשבמבה מתחת. במבה תקינה = 2 או 3 מחזורים של 1. אין במבות ארוכות מ-4, ויש לפחות 0 אחד בין במבות. Z=1 למחזור אחד על במבה תקינה. לכל היותר 2 T-FF, מצב התחלתי = "אין במבה".
- מצבים: a = אין במבה, b = במבה 1 מחזור, c = 2 מחזורים, d = 3 מחזורים. ה-Z=1 יוצא כש-X חוזר ל-0 מ-c או מ-d.

| PS | NS x=0 | NS x=1 | z x=0 | z x=1 |
|---|---|---|---|---|
| a=00 | 00 | 01 | 0 | 0 |
| b=01 | 00 | 10 | 0 | 0 |
| c=10 | 00 | 11 | 1 | 0 |
| d=11 | 00 | 00 | 1 | 0 |

- T = Y ⊕ y לכל ביט, ואז מפות קרנו: **T1 = x'y1 + xy2, T2 = x + y2, z = x'y1.**
- **מצבים לא בשימוש** (למשל אם יש רק 3 מצבים) → don't care בכל העמודות שלהם. זה עוזר בצמצום.
- **פונקציית המעבר עצמה** לא נחוצה לשלבים הבאים, אז בשאלת תכנון אפשר לדלג עליה אלא אם ביקשו.
- **SR/JK:** כותבים את כניסות ה-FF ישר מטבלת העירור (עם ה-d שלה), מה שמוסיף don't cares.
- כל פתרון שעומד בדרישות מקבל ניקוד מלא, גם אם הוא לא הכי יעיל.

### תזמון FSM
- מניחים FF מסוג Edge Triggered. התזמון תקין אם:
  - **T (מחזור) ≥ t_p(FF) + t_p(הלוגיקה הצירופית) + T_setup(FF)**
  - T_hold של הכניסות ארוך מספיק ביחס ל-T_hold של ה-FF, ו-T_hold של ה-FF קצר ביחס ל-t_p של הלוגיקה.
- **מכונות אסינכרוניות** (עם Latches במקום FF): אפשריות, אבל מסובכות ולא צפויות בגלל **מרוצים (races)**, קריטיים ולא קריטיים. ההשהיות תלויות בטמפרטורה, ייצור ורעש, ולכן בפועל כל המערכות המודרניות סינכרוניות.

### תהליך ניתוח מעגל נתון (תמצית למבחן)
1. כותבים משוואות עירור ופלט מהציור (J, K, T, D, Z).
2. מציבים במשוואה האופיינית → Y (מצב הבא). לדוגמה ל-JK: Y = Jy' + K'y. ל-D: Y = D.
3. טבלה → דיאגרמה → מריצים על הקלט הנתון → מתארים מה המכונה עושה.

### דוגמאות FSM מהמבחנים
- **2020, בדיקת קורונה (3 D-FF):** 4 ביטים בטור: חום, שיעול, קוצר נשימה, בידוד. Z=1 בביט הרביעי אם אחד משלושת הסימפטומים היה 1, או אם X=1 בביט הרביעי. מצבים: A → B/C (חום כן/לא) → D/E (חום או שיעול / אף אחד) → F/G (סימפטום כלשהו / אף אחד) → A. ב-F: Z=1 תמיד; ב-G: Z = X. **הגרסה המקבילית** (4 חיישנים במקביל) היא מעגל צירופי פשוט: Z = X1 + X2 + X3 + X4.
- **2020ב, כשירות מטוסים (3 T-FF):** 3 ביטים בטור: מנוע שמאל תקול, מנוע ימין תקול, מזגן מקולקל. Z=1 בביט השלישי אם יש **לפחות 2 תקלות מתוך 3** (majority). מצבים: A → B/C (תקלה ראשונה לא/כן) → D/E/F (0, 1 או 2 מנועים תקולים) → A. ב-D: Z=0, ב-E: Z=X, ב-F: Z=1. בפתרון הרשמי (לפי הקידוד שלו): Z = y1(y3 + x). **XOR של 3 הביטים לא מתאים** (parity ≠ majority: 3 תקלות → XOR=1 נכון, אבל 2 תקלות → XOR=0 שגוי). סעיף ג (צמצום מצבים) 🚫 לא בחומר.
- **2021א, מיון מלפפונים (2 JK):** 2 ביטים לכל מלפפון. ביט ראשון: גדול (1) / קטן (0). אחרי הביט השני: Z1 = האם היה גדול, Z2 = הביט השני. מצבים: A = התחלה, B = גדול (01), C = קטן (10), 11 = don't care. Z1 = y2, Z2 = X(y1 + y2), J1 = X'y2', K1 = 1, J2 = Xy1', K2 = 1. "האם אפשר Z2 בלבד עם FF אחד?" — כמה תשובות התקבלו (לא בשיטה הרגילה, כי Z2 תלוי בשני ה-FF).
- **2021ב, ניתוח (SR + D):** S1 = xy2, R1 = x', D2 = x(y1 + y2'), Z = xy1. Y1 = S1 + R1'y1 = x(y1 + y2). המכונה מזהה **שלוש 1 רצופות** (A→B→C→D, כל 0 מחזיר ל-A), Z=1 ב-C או D כש-X=1, וממשיכה להוציא 1 כל עוד הרצף נמשך. החלפת SR ב-JK לא משנה כלום (S=R=1 לא מופיע).
- **2022א, רכבות (2 T-FF):** חיישן: 00 = כלום, 10 = קטר, 01 = קרון. סוגי רכבות: קטר / קטר+קרון / קטר+קרון+קטר. פלט 01 אחרי קטר+קרון, 10 אחרי קטר+קרון+קטר, אחרת 00. פתרון מינימלי ב-2 מצבים (A = רגיל, B = "עבר קרון"): Z1 = y1X2', Z2 = y1X2, T1 = y1+X1. יש גם פתרונות עם 3 ו-4 מצבים. ריבוי קטרים בהתחלה: התכנון עדיין עובד.
- **2022ב, ניתוח (2 D-FF, כניסות X2X1):** Y = D לכל FF. המכונה מוציאה Z=1 אחרי שקיבלה את הרצף 00 → 01 → 10 → 11 (ספירה 0,1,2,3 בבינארי). סעיף המשך: מונה סינכרוני משני T-FF (T1=1, T2=y1) מזין את X2X1 ומייצר Z מחזורי.
- **2023א, מזהה ספרת BCD 6 או 7 (MSB ראשון, 3 D-FF):** מחפשים את התבנית 011x בכל קבוצה של 4 ביטים. 7 מצבים (עץ לפי ביט 1, 2, 3, ואז חזרה ל-A בביט הרביעי). Z = y1y3 (F=101). להשאיר רק 7: AND בין Z ל-X. Shift register של 4 ביטים **לא עובד**, כי הוא לא יודע איפה מתחילה כל ספרה ויזהה תבניות שחוצות גבול בין ספרות.
- **2023ב, מחבר טורי + זוגיות (2 D-FF):** X1,X2 נכנסים מה-LSB. Z1 = ביט הסכום, Z2 = זוגיות מספר ה-1 ב-Z1 עד כה. 4 מצבים = (carry, parity). D1 = (y1⊕y2)⊕(x1⊕x2). Z1 לבד מספיק FF אחד (רק carry). מ-Z2 לבד אי אפשר לדעת אם היה Cout (דוגמה נגדית).
- **2024א, מכונת גלידה (2 SR-FF):** לחיצה אחת = וניל (10), שתיים = שוקולד (01), שלוש = תות (11). הפלט יוצא כש-X חוזר ל-0 (או בלחיצה השלישית). מצבים: A = מנוחה, B = לחיצה 1, C = לחיצה 2. S1 = Xy2, R1 = y1, S2 = Xy1'y2', R2 = y2, Z1 = X'y2 + Xy1, Z2 = y1. שוקולד תקוע → במקומו תות: Z1new = Z1+Z2 עם MUX (S=Z1, I0=Z2, I1=Z1).
- **2024ב, ניתוח (T + JK):** T = y1+y2, J = xy1', K = x'+y1, Z1 = y1y2, Z2 = xy1 → Y1 = y1'y2, Y2 = xy1'. אפשר לשחזר עם shift register של 3 ביטים + שערים.
- **2025ב, פלט מושהה (3 D-FF):** X=1 פעם אחת → Z=1 אחרי 2 מחזורים נוספים; X=1 פעמיים → אחרי 3. המון don't cares. D1 = y1y3' + y2y3, D2 = y1'y2'y3 + y2y3', D3 = y1y3' + y2y3' + y3'X + y1'y2'y3X', Z = y1y3.
- **2025ג, ניתוח (2 JK):** J1 = K1 = X'+y2, J2 = K2 = X, Z1 = X'y1' + y1'y2 + Xy1y2', Z2 = X⊕y2, ומתברר ש-Y1 = Z1, Y2 = Z2. החלפה ל-T-FF: כן (J=K=T). ל-D-FF: כן (D = T⊕Q). ל-SR: כן (S = JQ', R = KQ).
- **רמז חוזר:** כשהקלט מגיע במקביל ולא בטור, בדרך כלל אין צורך ב-FSM ומספיק מעגל צירופי.

## 17. מערכי זיכרון (שבוע 11A — בחומר; RAM/SSD מ-11B לא במבחן)

### משפחות זיכרון (מוצק בלבד)
- **Volatile (Read-Write):** Random Access: **SRAM**, **DRAM**. Non-Random: FIFO, LIFO, Shift Register.
- **Non-Volatile Read-Write:** EPROM, E²PROM, FLASH.
- **Read-Only (ROM):** Mask-Programmed, Programmable (PROM).

### מבנה כללי של מערך N×M
- N מילים (words) של M ביטים. במבנה נאיבי צריך N קווי בחירה. **Decoder** מצמצם אותם ל-**K = log₂N** קווי כתובת (A0…A_{K−1}).
- ביציאה יש MUX שבוחר את המילה (בעיקר ב-RAM יש עוד רכיבים סביב, לקריאה/כתיבה מהירה, למשל Bit line ו-Bit line').

### ROM
- מערך שמוגדר פעם אחת ואחר כך לא משתנה. **כל מעגל צירופי אפשר לראות כ-ROM.**
- **OR-Gated Array (PROM):** Decoder קבוע (כל 2ⁿ המינטרמים) + מערך OR מתוכנת. מתכנתים ע"י "שריפת" חיבורים חשמלית. אחרי השריפה אי אפשר לשנות.
- גודל ROM = 2ⁿ × m (n כניסות/כתובת, m יציאות). מממשים ישר מטבלת האמת. המבחן לא דורש לצייר את המפענח.
  - 2020: מחבר שני מספרים של 2 ביטים ב-ROM: 4 כניסות, 3 יציאות → **16×3**.
  - דוגמה מההרצאה (2023ב): f(a,b,c) = Σ(0,2,4,6,7), g(a,b,c) = Σ(0,1,2,3,4,5) ב-ROM 8×2.
- **EPROM / EEPROM:** ROM שאפשר למחוק ולכתוב מחדש מספר מוגבל של פעמים (עדכוני Firmware, BIOS). SSD הוא התפתחות של הטכנולוגיה (גם הוא עם מספר כתיבות מוגבל).

### PLA ו-PAL
- **PLA nXmXp:** n כניסות (עם היפוכים), p שורות AND (מכפלות, לא כל 2ⁿ המינטרמים), m עמודות OR (יציאות). שני המישורים מתוכנתים.
- **PAL:** מקרה פרטי של PLA שבו מישור ה-OR קבוע ורק מישור ה-AND מתוכנת.
- המטרה ב-PLA: לצמצם p ע"י **שיתוף מכפלות בין הפונקציות**. לפעמים צריך לבחור ביטוי לא-מינימלי לאחת הפונקציות כדי לשתף.
  - FA ב-PLA: n=3, p=7 מכפלות (מינטרמים, ABC משותף), m=2.
  - 2024ב: f2 = C', h = A'+C' עם p ≤ 2: n=2 (A,C), p=2 (A', C'), m=2.
  - דוגמה מההרצאה (2023א): f(a,b,c) = cb' + ab, g(a,b,c,d) = a'b'cd.
  - **2022ב, אחסון 4 מספרים ב-2sc** (S1S0 = 00:−7, 01:−1, 10:1, 11:7 → 1001, 1111, 0001, 0111): Out3 = S1', Out2 = Out1 = S0, Out0 = 1. בפתרון הרשמי: n=2, m=4 (או 3, כי Out0 קבוע), p=3 (המכפלות S1', S0 וקבוע 1). פתרון קנוני "ישר" (כמו ROM) עובד גם, עם p=4.

## 17ב. תוספות מהתרגולים ומתרגילי הבית
- **Priority Encoder עם יציאת V (Valid)** (תרגול 7): V = 0 כשאף כניסה לא דולקת. X1 = D3 + D2, X0 = D3 + D1D2'.
- **השהיה אסימטרית** (תרגול 5, WK8A): tpHL ≠ tpLH. f = AB ⊕ CD, tpHL(AND) = 20, tpLH(AND) = 10, XOR = 5. במעבר 1100 → 1011 ב-t=60 יש ריצוד ב-75–85.
- **Static hazard מסוג 0** (תרגיל בית 5): Z = (A'+B)(B'+C) עם delay 10. A=1, C=0, B↑ ב-30 → Z = 1 בין 50 ל-60. במעגל PoS כזה אפשרי רק hazard מסוג 0.
- **x + y ≤ 7 עם FA ושער יחיד** (תרגול 6): מחבר 4 ביט, ואז NOR על Cout ו-S3.
- **כפל 2 ביט מ-HA ושערי AND** (תרגול 6, WK6A).
- **מחבר טורי** (תרגול 8): FA אחד + D-FF ששומר את ה-carry, ושני shift registers.
- **"מנעול" עם shift register** (תרגול 8): מזהה מילה של 4 ביט. הבעיה: חפיפה (1111 1111).
- **מונה מעלה/מטה** (תרגול 8): מונה מעלה + מונה מטה + מחבר → mod 16.
- **JK מ-D-FF + MUX2:1 + NOT** (תרגיל בית 7+8, בונוס). **מונה ripple מ-JK** (התרגיל): Q של שלב אחד הוא השעון של הבא → סופר **מטה**.
- **"לפחות 2 מתוך 4"** = Σ(7,11,13,14,15) = wxy + wxz + wyz + xyz; עם 2 FA + AND (תרגיל בית 6).
- **K מחלק את 210** (K ∈ 1..15) → Z = x1x0' + x3'x0 + x2x1; Decoder 3x8 + 2 שערים (תרגיל בית 6).
- **16 נורות מ-2 Decoder 2x4 + AND** (תרגיל בית 6).
- **ROM למכפל של שני מספרים בני 4 ביט:** 256 × 8 (תרגיל בית 11).
- **שלמות עם "שימוש בפעולה שכבר מימשנו"** (דף עזר): f = a + b'c. f(0,b,1) = b' (NOT), ואז f(0,b,c') = (b+c)' (NOR) → שלמה.

## 18א. שערים ורכיבים נוספים (מהמבחנים)
- **ביט זוגיות (even parity):** P = שרשרת XOR של כל הביטים. אפשר לממש עם XOR בלבד (fan-in 2), בלי קבועים.
- **מרחק המינג:** ביט יחיד = XOR. לשני ביטים: H<2 → שני XOR נכנסים ל-HA, הפלט = (Cout)' (Cout=1 רק כששני הביטים שונים). H ∈ {0,2} → XNOR של שני ה-XOR (או Decoder + OR).
- **השוואת שני ביטים (שווים=1) = XNOR.** מ-NAND בלבד: XOR מ-4 NAND + NAND כמהפך.
- **מזהה מספר זוגי (≠0):** f = D'(A+B+C) = CD' + BD' + AD'; אם 0 נחשב זוגי: f = D'.

## 19. טיפים מהמבחנים
- "Note: not A', B'...": תמיד לחשוב איך לייצר היפוך עם הרכיבים הנתונים (MUX2:1 עם 1/0, יציאת Q' של FF, NAND עם כניסות מחוברות).
- כשמוגבלים למספר שערים: לחפש XOR/XNOR בתוך הביטוי (למשל A'BD + A'B'D' = A'(B⊙D)).
- כשמוגבלים ב-fan-in: להוציא גורם משותף לפני שבונים עץ שערים.
- בשאלות "האם אפשר?": אם רכיב צירופי, כמעט תמיד כן. אם נדרש זיכרון/מצב ומדובר ברכיב חסר זיכרון (או להפך), כנראה לא.
- גם פתרון שונה מהפתרון הרשמי מקבל ניקוד מלא אם הוא עומד בתנאי השאלה.
