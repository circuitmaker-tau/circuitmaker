## 1. סמנטיקת המנוע (כללים מחייבים)

### E1. זמן
- המנוע עובד רק בטיקים שלמים. `TICKS_PER_UNIT = 10`, כלומר טיק = 0.1 יחידת זמן.
- Tp מוזן בממשק כמספר עשרוני בקפיצות של 0.1, ביחידה של המעגל (`none` / `ns` / `s`). בתוך המנוע: `ticks = Math.round(Tp * 10)`.
- Tp = 0 מותר (השהיה אפס). המבחנים משתמשים בזה, למשל "Tp של ה-T-FF הוא 0, של השערים 0.5".

### E2. מודל השהיה: transport
- כששער מחושב מחדש בזמן t ומקבל ערך יציאה חדש v, נקבע אירוע `(t + d(v), out, v)`.
- **כל פולס עובר**, גם קצר מה-Tp. אין סינון inertial.
- **השהיה אסימטרית** (החלטה 7, נתמכת): `d(1) = tpLH`, `d(0) = tpHL`. ברירת המחדל היא `tpLH = tpHL = Tp`. הקורס משתמש בזה בשתי דוגמאות: WK8A ותרגול 5 (`tpHL(AND)=20, tpLH(AND)=10, XOR=5`).
- אם נקבעו כמה אירועים לאותו פורט באותו זמן, האחרון שנקבע קובע.
- **ביטול אירועים כש-tpLH ≠ tpHL (נוסף 03.11, נמצא בהשוואה מול Icarus):** כשההשהיות שונות, ערך חדש יכול להגיע לפני ערך ישן שעדיין בדרך. במקרה כזה הערך החדש מבטל כל ערך של אותה יציאה שאמור להגיע באותו זמן או מאוחר יותר. זה כלל ה-transport הסטנדרטי (VHDL). בלי הכלל הערך הישן נוחת אחרון, והיציאה נשארת שונה מהפונקציה של הכניסות עד השינוי הבא. עם השהיה אחידה אף אירוע לא מתבטל, כך שכל מקרי TEST_CIRCUITS לא משתנים.

### E3. עיבוד לפי חותמת זמן (delta cycles)
1. שולפים מהתור **את כל** האירועים בזמן t.
2. שומרים צילום של ערכי כל החוטים **לפני** t (`before`).
3. מחילים את כל השינויים. רק חוט שהערך שלו באמת השתנה נרשם ב-Waveform ומפעיל fanout.
4. מחשבים מחדש את השערים שמושפעים. אירוע עם d = 0 נכנס לאותו זמן t ומעובד כ-delta cycle נוסף.
5. **הגנה מלולאה:** אם בזמן אחד יש יותר מ-1000 delta cycles, המנוע עוצר ומדווח "לולאת משוב בהשהיה אפס". זה יכול לקרות למשל בטבעת מהפכים עם Tp=0.

### E4. Flip-Flop שמגיב לקצה
- כל ה-FF מגיבים ל**עליית** שעון (0→1). זו מוסכמת הקורס בכל המבחנים. מעבר X→1 או 0→X **אינו** קצה, והוא הופך את Q ל-X.
- **דגימה "רגע לפני הקצה":** ה-FF משתמש בערכי D/T/J/K/S/R כפי שהיו **לפני** כל אירוע באותה חותמת זמן, כלומר מצילום ה-`before` של E3.
  - המקור: פתרון מבחן 2026ב 2D: "The sampling is always just before the clk change". גם 2026ג 2D תלוי בזה: D משתנה בדיוק ברגע עליית השעון, וה-FF דוגם את הערך הישן.
- היציאה משתנה ב-`t_edge + Tp(FF)`. Q' משתנה באותו זמן.
- משוואות (דף הנוסחאות של המבחן):

| FF | Q(t+1) |
|---|---|
| D | D |
| T | T ⊕ y |
| JK | J·y' + K'·y |
| SR | S + R'·y (S=R=1 אסור) |

- **SR-FF עם S=R=1 בזמן קצה:** Q ← X, ומוצגת אזהרה "מצב אסור". (בתכנון FSM עם SR זה don't care, ובמבחנים שואלים "האם אפשר להחליף ל-JK?", אז האזהרה היא חלק מהערך הלימודי.)

### E5. אתחול (t = 0)
- במבחנים תמיד נותנים מצב התחלתי ("At the beginning Q0, Q1, Q2 = 0, 1, 1"), והוא תמיד עקבי עם הלוגיקה. לכן האתחול הוא:
  1. FF ו-latch: `init` מה-props. ברירת המחדל ל-FF היא 0, ול-latch היא X (החלטה 8).
  2. INPUT / CONST / CLOCK: הערך ההתחלתי שלהם.
  3. **התייצבות בהשהיה אפס:** מעריכים את כל הלוגיקה הצירופית עד שהיא יציבה, בלי השהיות, ורק אז מתחילים את הזמן. אם אין התייצבות (למשל טבעת מהפכים), החוטים שלא התייצבו מקבלים X ומוצגת אזהרה.
- כניסה לא מחוברת = X.

### E6. שעון (CLOCK)
- props: `halfPeriod` (ברירת מחדל 1 יחידה), `startLevel` (ברירת מחדל 0).
- השעון מתחיל ב-`startLevel` ומתחלף כל `halfPeriod`. עם ברירות המחדל: עלייה ב-t=1, 3, 5... בדיוק כמו בגרפים של המבחנים: "CLK switches its state every 1 second (a full clock cycle takes two seconds)".

### E7. כללי X (ערך לא מוגדר)
| רכיב | כלל |
|---|---|
| AND / NAND | אם יש כניסה 0, היציאה 0 (או 1 ב-NAND) גם כשיש X. אחרת, אם יש X, היציאה X |
| OR / NOR | אם יש כניסה 1, היציאה 1 (או 0 ב-NOR) גם כשיש X. אחרת, אם יש X, היציאה X |
| NOT, BUF, XOR, XNOR | כל X בכניסה → X |
| MUX | אם הבורר X: אם כל הכניסות שהבורר יכול לבחור שוות, היציאה היא הערך הזה; אחרת X. אם הבורר מוגדר: הכניסה שנבחרה (גם אם היא X) |
| Decoder | אם En=0, כל היציאות 0. אם En=X, או יש X בכניסות: כל יציאה שיכולה להיות 1 מקבלת X, ושאר היציאות 0 |
| FF | X בכניסת נתונים שנדגמת → Q=X. קצה לא מוגדר (E4) → Q=X |
| HA / FA | מחושב לכל יציאה בנפרד לפי הכללים של השערים שהיא בנויה מהם |

### E8. זיהוי תנודות ו-glitches
- **תנודה:** חוט שמחליף ערך יותר מ-N פעמים (ברירת מחדל 50) בחלון זמן, בלי שינוי כניסה חיצונית. מסמנים אותו ומציגים אזהרה (התחייבות מתכנית העבודה).
- **glitch:** פולס שמתחיל ונגמר בתוך חלון של מעבר כניסה בודד. המנוע מחזיר אותו עם זמן התחלה ורוחב, וכך דיאגרמת הזמנים יכולה "למדוד משך ריצוד".

## 2. ספריית הרכיבים

> **שמות פורטים (החלטה 9):** אינדקסים מ-0, כמו במבחני 2026: `S0..`, `I0..`, `D0..`, `Q0..`, כש-0 הוא ה-LSB. בשקפים האינדקס מתחיל מ-1 (`S1..Sn`, `x1..xn`), וזה יופיע בעזרה של כל רכיב.

### 2.1 קבועים, כניסות ויציאות
| type | פורטים | התנהגות | Tp ברירת מחדל |
|---|---|---|---|
| `CONST0` / `CONST1` | out | 0 / 1 קבוע. במבחנים: "You can use the constants 0 and 1" | 0 |
| `INPUT` (מתג) | out | ערך ש-המשתמש מחליף בלחיצה, או לפי רצף stimuli מתוזמן | 0 |
| `CLOCK` | out | ראו E6 | 0 |
| `OUTPUT` (נורה/בדיקה) | in | מציג את הערך. כל חוט אפשר להוסיף לדיאגרמת הזמנים | — |

### 2.2 שערים (דף הנוסחאות, "שערים לוגיים")
| type | כניסות | פונקציה | הערה מהקורס |
|---|---|---|---|
| `NOT` | 1 | x' | |
| `BUF` | 1 | x | "Buffer (משהה)": שימושי להשהיה בלבד |
| `AND` | 2–4 | x·y | fan-in = מספר הכניסות. מגבלות fan-in הן נושא בקורס |
| `OR` | 2–4 | x+y | |
| `NAND` | 2–4 | (xy)' = x↑y | שלם פונקציונלית; כמהפך: שתי כניסות מחוברות |
| `NOR` | 2–4 | (x+y)' = x↓y | שלם פונקציונלית |
| `XOR` | 2–4 | x⊕y; עם יותר מ-2 כניסות = זוגיות | "בדיקת אי-שוויון / זוגיות / חיבור מודולו 2" |
| `XNOR` | 2 | x⊙y | "בדיקת שוויון" |

### 2.3 רכיבים צירופיים
| type | כניסות | יציאות | התנהגות |
|---|---|---|---|
| `HALF_ADDER` | A, B | S, C | S = A⊕B, C = AB |
| `FULL_ADDER` | A, B, Cin | S, Cout | S = A⊕B⊕Cin, Cout = AB + Cin(A⊕B) (דף הנוסחאות) |
| `MUX2` | I0, I1, S0 | f | f = S0'·I0 + S0·I1 |
| `MUX4` | I0–I3, S0, S1 | f | f = Σ mᵢ·Iᵢ, כאשר `S1S0=01 → I1` |
| `MUX8` | I0–I7, S0–S2 | f | כנ"ל. רצוי, כי מופיע במבחנים |
| `MUX16` | I0–I15, S0–S3 | f | מופיע במבחנים כ"MUX 16:1 + 0/1" (B2.1, 2025א 2C). **ממומש (04.11)** |
| `DEC2x4` | I0, I1, En | D0–D3 | Dᵢ = En·mᵢ (I0 = LSB) |
| `DEC3x8` | I0–I2, En | D0–D7 | כנ"ל |
| `ENC4x2` (לימודי) | D0–D3, En | X1, X0 | קלט חוקי = בדיוק כניסה אחת 1. אחרת **X** בשתי היציאות (2026א 2C: "a normal encoder expects a 1 in a single input only… the outputs are undefined") |
| `PRIORITY_ENC4x2` | D0–D3, En | X1, X0, **V** | הכניסה הגבוהה ביותר שדולקת קובעת. V (Valid) = 0 כשאין אף כניסה דולקת (תרגול 7). X1 = D3+D2, X0 = D3 + D1·D2' |
| `PRIORITY_ENC8x3` | D0–D7, En | X2–X0, V | הרחבה. 2026א 2C משתמש ב-8:3 |

### 2.4 רכיבים עקיבים
| type | כניסות | יציאות | התנהגות |
|---|---|---|---|
| `SR_LATCH` | S, R | Q, Q' | מבוסס NOR, אסינכרוני (מגיב מיד, אחרי Tp). S=1,R=0 → 1; S=0,R=1 → 0; S=R=0 → שמירה; **S=R=1 → Q=Q'=0** (מוגדר; 2026ג 2C: "S=R=1 works here… outputs will be Q=Q'=0"). מעבר בבת אחת מ-11 ל-00 → **X** (מרוץ) עם אזהרה |
| `D_LATCH` | D, En | Q, Q' | Gated: כש-En=1, Q=D (שקוף); כש-En=0 שומר |
| `D_FF` | D, CLK | Q, Q' | E4 |
| `T_FF` | T, CLK | Q, Q' | E4 |
| `JK_FF` | J, K, CLK | Q, Q' | E4. J=K=0 שומר, J=K=1 הופך |
| `SR_FF` | S, R, CLK | Q, Q' | E4. הרחבה, כי מופיע במבחנים (FSM עם 2 SR-FF) |
| `REGISTER4` | D0–D3, CLK | Q0–Q3 | 4×D-FF על אותו שעון |
| `COUNTER4` | CLK, RESET | Q0–Q3 | סופר למעלה בכל עליית שעון; RESET=1 מאפס |
| — | CLR' / PRE' אסינכרוניים | | **ממומש (04.11)** ב-D/T/JK/SR flip-flop, כשהמאפיין `async` דולק. Active Low לפי WK8A ("nullifying inputs will always be async"): CLR' = 0 → Q = 0 מיד (אחרי Tp), PRE' = 0 → Q = 1, בלי קשר לשעון, ובזמן שאחד מהם פעיל קצה השעון לא משפיע. שניהם 0 יחד → X עם אזהרה. כניסה לא מחוברת = לא פעילה (1), בלי אזהרה. X באחד מהם משאיר את Q רק אם הוא כבר שווה לערך שהכניסה הייתה כופה |

- props משותפים ל-FF ול-latch: `init: 0 | 1 | 'X'` ו-`Tp`.
- **סדר פורטים בסמל:** CLK עם משולש (Edge Triggered); עיגול מסמן Active Low.

## 3. התאמה למה שהמבחנים בודקים (מה המנוע חייב לשחזר)
| דפוס במבחן | שנים | דרישת מנוע |
|---|---|---|
| דיאגרמת זמנים של שרשרת FF (Tp זניח) | 2024א, 2024ב, 2025ג, 2025א (מונה 4 JK) | E4, E6. T/JK/D-FF |
| **דיאגרמת זמנים עם Tp מפורש (0.5s, 1s) לשערים ול-FF** | **2025ב, 2026א, 2026ב, 2026ג** (בכל מבחני 2026!) | E1 (Tp עשרוני), E2, E4 (דגימה לפני הקצה), E5 (אתחול נתון) |
| static hazard בדיאגרמת זמנים | WK5, תרגיל בית 5 (delay 10), תרגול 5 (אסימטרי) | E2, E8 |
| latch עם פלט "לא ידוע" | 2026ג 2C | E7 (X), SR_LATCH |
| Encoder רגיל לעומת Priority | 2026א 2C | ENC4x2 עם X, PRIORITY_ENC |
| FSM: ניתוח ותכנון | כל המבחנים | FF + שערים (העורך לא חייב "לדעת" FSM) |
